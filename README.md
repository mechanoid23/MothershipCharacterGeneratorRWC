# Mothership Character Generator — Rimward Colonies (RWC)

Module ID: `mothership-character-creator-rwc`

**Install in Foundry VTT:** `https://raw.githubusercontent.com/mechanoid23/MothershipCharacterGeneratorRWC/master/module.json`

**Requires:** [fvtt_mosh_1e_rwc](https://github.com/mechanoid23/fvtt_mosh_1e_rwc) (RWC compendium), [fvtt_mosh_1e_psg](https://github.com/mechanoid23/fvtt_mosh_1e_psg) (PSG compendium), and the [mosh-fork system](https://raw.githubusercontent.com/mechanoid23/fvtt-mosh-fork/master/system.json)

**Standalone:** this module duplicates all macros from MothershipCharacterGenerator so it does NOT require MCG as a runtime dependency. Both generators can be installed side-by-side.

## How to use
* Install fvtt_mosh_1e_rwc and fvtt_mosh_1e_psg.
* Enable the Mothership Character Generator RWC module in your world.
* Open the **Character Generation Journal** compendium.
* Open the **Character Creation** journal.
* Select an empty character from **User Configuration** OR ask your GM to give you **Create New Actors** permission.
* Follow the instructions step-by-step and click on the macro buttons as needed.
* After choosing your class, run the **Choose Skills** macro to select your starting skills.

## Compendium packs
- **Character Generator Journal** — step-by-step character creation journal for RWC classes
- **Character Generator Macros** — full set of class macros (including PSG classes duplicated for standalone use) plus the Choose Skills macro
- **Character Generator Tables** — supporting rolltables
